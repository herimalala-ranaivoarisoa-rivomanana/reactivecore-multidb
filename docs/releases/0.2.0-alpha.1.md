## ReactiveCore MultiDB 0.2.0-alpha.1

This is the first prerelease from the ReactiveCore MultiDB repository.

- Run the same item application on PostgreSQL 16 or the MySQL 8.4 preview. The structured tenant data interface supports list, get, insert, update, and delete operations.
- Prevent stale updates and deletes with a row version. The Next.js example preserves offline drafts, shows conflicts, and can resubmit against the current version.
- Download the Linux amd64 runtime image and TypeScript SDK archive. Verify both files against `SHA256SUMS` before installing.

The release checks run the packaged image with PostgreSQL and MySQL and exercise the Next.js example in Chromium with the packaged SDK. They cover mutation rollback and replay, tenant isolation, SSE, worker delivery, and offline conflict resolution. PostgreSQL backup and restore are also tested.

MySQL is a preview for applications built on the structured tenant data interface. PostgreSQL handles existing application SQL. Validation on specific cloud services remains a separate effort.
