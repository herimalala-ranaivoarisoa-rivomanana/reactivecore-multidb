## ReactiveCore MultiDB 0.2.0-alpha.2

- Filter and paginate tenant reads on PostgreSQL 16 and MySQL 8.4.
- Lock a row inside a mutation for atomic business decisions. The reservation example verifies that one of two concurrent requests succeeds and that replay returns its stored result.
- Join tenant-scoped tables and compute live grouped counts and sums. The billing example uses the same handler on PostgreSQL and MySQL.
- Opt in to native prepared MySQL statements for trusted handlers. The application must scope its own native SQL to the tenant.
- Rehearse a MySQL upgrade from the published `v0.2.0-alpha.1` image and restore a logical backup. The release checks compare restored data, receipts, the change journal, and migration records.

The release includes the Linux amd64 runtime image, the TypeScript SDK archive, and checksums. The release workflow tests both engines and the Next.js offline conflict example. The managed MySQL verification also passes on local MySQL 8.4 with TLS enabled. Validation on external cloud providers remains pending, and MySQL remains a preview.
