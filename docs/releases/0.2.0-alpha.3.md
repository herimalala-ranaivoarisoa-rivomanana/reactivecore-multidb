## ReactiveCore MultiDB 0.2.0-alpha.3

- Verify API replica failover on PostgreSQL 16 and MySQL 8.4. The SDK subscription reconnects, catches up, and receives new writes. Replaying a mutation through the surviving API returns the original receipt.
- Verify recovery after the API and worker lose their database connections. The test covers a committed mutation whose response was lost, a retry after reconnection, and recovery of SSE and outbox delivery.
- Rehearse managed MySQL recovery with the new `checkpoint` and `restore` workflow modes. The restore check compares the original mutation receipt and verifies SSE and outbox delivery for a new mutation. The drill passed with a logical backup restored to a separate local MySQL 8.4 instance over TLS.

This prerelease includes the Linux amd64 runtime image, the TypeScript SDK archive, and SHA-256 checksums. PostgreSQL 16 is the established engine. MySQL 8.4 remains a preview for applications using the structured tenant data interface. Validation on Neon and Amazon RDS, including an RDS snapshot restore, is pending.
